# Electronic-sales-Dashboard
Interactive Power BI dashboard for analyzing electronic sales data of a company over a one year period.
# Problem Statement
Understanding sales trends and customer behavior to identify purchasing patterns and assess product performance, enabling data-driven decision-making for optimizing sales strategies
# Dataset Source
https://www.kaggle.com/datasets/cameronseamons/electronic-sales-sep2023-sep2024
# Data Preperation Steps
Extracted Year and Month columns from the Purchase Date column to enable time-based analysis of sales
